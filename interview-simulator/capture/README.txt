AI Interview Practice Assistant - Step 1 (Capture)

1. Install Python 3.10+ from python.org (tick "Add Python to PATH").
2. Double-click run.bat
3. Enter a session code (e.g. TEST01).
4. Play some sound, speak, type, click. Press Ctrl+C to stop.
5. Results: sessions\<time>_<code>\  (audio\*.wav, screen\*.png, events.jsonl.gz)
Use headphones to avoid echo.
